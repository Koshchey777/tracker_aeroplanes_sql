# ✈️ Tracker Aeroplanes SQL

Проект-трекер самолётов, который собирает данные о воздушном трафике 
в реальном времени через открытые API и сохраняет их в PostgreSQL для последующего анализа.

## 🌟 Возможности

- 🌍 Получение bounding box стран через **Nominatim (OpenStreetMap)**
- 🛩 Сбор данных о самолётах через **OpenSky Network**
- 🗄 Хранение данных в **PostgreSQL** со связью «страна → самолёты» (Foreign Key)
- 📊 Консольный интерфейс с 6 аналитическими запросами:
  1. Количество самолётов по странам
  2. Полный список самолётов
  3. Средняя скорость
  4. Средняя высота
  5. Самолёты выше средней скорости
  6. Поиск по позывному (callsign)


## 🚀 Установка и запуск

### 1. Клонирование
```
git clone https://github.com/Koshchey777/tracker_aeroplanes_sql.git
cd tracker_aeroplanes_sql 
```

### 2. Установка зависимостей (через Poetry)
```
poetry install
poetry shell
```

### 3. Настройка PostgreSQL
Убедитесь, что PostgreSQL запущен локально и доступен по стандартному порту 5432


### 4. Конфигурация
Скопируйте шаблон и заполните свои данные:
```
cp .env.template .env
```


### 5. Запуск
```
python main.py
```

При первом запуске скрипт:
+ создаст базу air (пересоздаст, если существует),
+ создаст таблицы countries и airplanes,
+ скачает данные о самолётах для стран из списка COUNTRIES,
+ откроет интерактивное меню.
